# Модернизация веб-интерфейса детского технопарка «Инжинириум МГТУ им. Н.Э. Баумана»

Проект выполнен в рамках тестового задания. В ходе работы был проведен визуальный и функциональный аудит текущего официального сайта «Инжинириум» (inginirium.ru), сформирован список улучшений и сверстана обновленная, адаптивная версия ключевых страниц.


## 🔍 Часть 1. UI/UX Аудит текущего сайта (Что было не так?)

В ходе анализа оригинального сайта были выявлены следующие проблемы интерфейса, которые ухудшают восприятие бренда и усложняют запись на курсы:

1. **Проблема с «овалами» в главном меню:** При наведении на пункты меню или при их активации вокруг текста появляются массивные цветные овалы. Это визуально перегружает шапку сайта и выглядит устарело.
2. **Бесконечные дублирующие формы:** На оригинальном сайте формы обратной связи («Оставить заявку», «Записаться») встроены прямо в тело страницы и повторяются по несколько раз. Это создает визуальный «мусор» и растягивает страницу.
3. **Хаос в карточках курсов:** Информация о возрасте, ценах и направлениях на оригинальном сайте подана сплошным потоком, из-за чего родителю трудно быстро сравнить программы между собой.
4. **Сложная навигация в блоке лагеря:** Информация о сменах летнего лагеря перегружена текстом, отсутствует четкая разбивка по датам и возрастным группам.


## 🛠️ Часть 2. Что было сделано в редизайне (Как мы это исправили?)

1. **Очистка шапки сайта:** Убраны ломающие верстку овалы из меню. Теперь активная страница подсвечивается изящным современным нижним подчеркиванием.
2. **Оптимизация форм через модальное окно (Поп-ап):** Все дублирующиеся формы со страниц были удалены. Вместо них настроена одна аккуратная кнопка «Записаться». При клике на нее JavaScript плавно открывает единое модальное окно поверх сайта.
3. **Структурированная сетка курсов и лагеря:** Программы обучения и смены лагеря упакованы в аккуратные карточки (Grid-сетка). Четко разделены возрастные теги, цены и описания. 


## 🧠 Часть 3. Реализованный JavaScript (Vanilla JS)

Сайт оживлен с помощью чистого JavaScript без использования тяжелых сторонних библиотек:

* **Интерактивные табы (Направления обучения):** Переключение между «Робототехникой», «Программированием» и «3D» происходит мгновенно на одной странице без ее перезагрузки. Настроена поддержка управления с клавиатуры (кнопками Home, End и стрелками) по стандартам веб-доступности W3C ARIA.
* **Анимация при скролле (Intersection Observer):** Карточки курсов и элементы лагеря красиво и плавно «вплывают» на экран ровно в тот момент, когда пользователь доскролливает до нужного блока.
* **«Умные» живые счетчики:** В блоке статистики цифры («10+ лет опыта» и т.д.) динамически бегут от нуля до целевого значения при появлении блока на экране. Скорость анимации завязана на системное время, поэтому она работает одинаково плавно на любых мониторах.
* **Маска для телефона:** В форме записи настроено автоматическое форматирование номера. Когда пользователь вводит цифры, скрипт сам превращает их в красивый вид `+7 (999) 000-00-00`.


## 📂 Структура репозитория:
* `index.html` — модернизированная главная страница.
* `summer-camp.html` — страница летнего инженерного лагеря.
* `css/global.css` / `js/global.js` — общие для всего сайта стили, логика шапки и поп-апа.
* `css/index.css` / `js/index.js` — уникальный дизайн и интерактив для главной страницы.
* `js/summer-camp.css` / `js/summer-camp.js` — база данных курсов и движок их отображения на сайте.
